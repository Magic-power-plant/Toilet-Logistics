# 马桶物流

马桶物流是一个 Dung Pipe 附属模组，提供马桶、管道和马桶搋子……

## 依赖

- Dung Pipe 1.2（前置）
- The One Probe Community Edition（联动）
- Mekanism（联动）

## 内容

### 马桶

模组提供 16 个颜色的陶瓦马桶。

- 默认状态为关闭，右键可以打开或关闭，红石信号也可以控制马桶盖状态。
- 手持同色马桶右键可以绑定 UUID 。绑定信息会保存到马桶和物品中。
- 绑定信息会显示在物品 tooltip 中；安装 The One Probe 时，对准马桶可以查看绑定标识以及是否找到其他同频道马桶。

#### 频道传输

同一个 UUID 频道内的马桶使用点对点方式传输，不在马桶内部保存物品、流体或气体：

- 物品端口位于马桶底部，只与下方的漏斗或物品管道交互。
- 流体端口位于马桶背面，只与背面的流体管道或流体容器交互。
- 气体端口位于马桶顶部，只与顶部的气体管道或气体设备交互。
- 物品、流体和气体会在频道内的其他马桶对应端口之间传输，不同 UUID 频道互不影响。
- 接收端的马桶会自动弹出物品、流体、气体。

#### 马桶水与流体

- 在打开的马桶上使用水桶或其他流体容器，可以设置马桶显示的流体纹理。
- 通过容器手动注入的流体可以再次用容器取出；由频道传输产生的显示流体不能直接取出。
- 手持马桶搋子潜行右键马桶可以清空马桶水。
- 流体传输会同步同频道马桶的显示类型；手动注入的流体显示优先级更高。
- 发光流体会让马桶提供对应等级的光照。

#### 玩家传送

当马桶已绑定、处于打开状态且有马桶水时，玩家站在马桶上并关闭马桶盖，会被传送到同 UUID 频道中随机选择的其他打开马桶。传送成功后会播放冲水音效并消耗频道马桶水；传送时玩家会受到一次对应流体的接触效果，例如岩浆会使玩家着火。

#### 掉落物处理

打开的马桶会吸收上方漏斗范围内的掉落物：

- 已绑定马桶：掉落物会从目标马桶顶部喷出，落在目标马桶附近。
- 未绑定马桶：掉落物会尝试存入马桶下方的容器。

### 泄水阀

它是输出方向管道：

- 从模型朝向一侧读取源容器。
- 向相反一侧输出物品、流体和气体。
- 物品每 tick 传输源容器中的一个完整槽位，最多 64 个物品。
- 流体最大传输速度为 64000 mB/t；气体最大传输速度为 64000 mB/t。
- 物品没有目标容器时会在泄水阀位置生成掉落物；流体和气体需要目标处理器或管道才能传输。。

### 抽粪管

它的方向与泄水阀相反，是输入方向的管道：

- 从模型朝向的相反一侧读取源容器。
- 向模型朝向一侧输入物品、流体和气体。
- 物品、流体和气体都要求两端存在对应的容器或处理器。
- 没有目标端时不会抽走源端物品，也不会生成掉落物。
- 物品、流体和气体的传输上限与泄水阀相同。

### 马桶搋子

马桶搋子是扳手类工具：

- 右键支持旋转有方向性的方块。
- 手持马桶搋子潜行右键马桶可以清空马桶水。
- 可以通过玩家装备栏或其他装备方式戴在头盔栏，手持右键空气不会自动穿戴。
- 戴在头上时提供 1 点护甲值，并每 3 秒给予 4 秒反胃效果。
